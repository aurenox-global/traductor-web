# Traductor — Web

Minimalist bilingual (EN/ES) site for **Traductor**, a 100% offline Android translator
(**NLLB-200 · ONNX** for translation, plus Whisper · VAD · OCR · Piper TTS).
Light/dark theme, no external dependencies.

**App source code:** https://github.com/aurenox-global/traductor

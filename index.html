Qué esWhat is it

Traductor es una app nativa de Android que traduce texto, voz y fotos sin salir nunca del dispositivo.

Los modelos de inteligencia artificial se descargan una sola vez (primera ejecución, se recomienda Wi-Fi) y a partir de ahí todo —la traducción, el reconocimiento de voz, el OCR y la lectura en voz alta— ocurre en el teléfono. Puedes usarla en modo avión.

Traductor is a native Android app that translates text, voice and photos without ever leaving the device.

The AI models are downloaded once (first run, Wi-Fi recommended) and from then on everything —translation, speech recognition, OCR and read-aloud— happens on the phone. You can use it in airplane mode.

🔒 Sin cuentas, sin anuncios, sin analíticas. Tu voz, tus fotos y tus textos no salen del teléfono. 🔒 No accounts, no ads, no analytics. Your voice, photos and text never leave the phone.

Cómo funcionaHow it works

Un único pipeline (Kotlin) alimenta los motores locales (ONNX Runtime + whisper.cpp). A single pipeline (Kotlin) drives the local engines (ONNX Runtime + whisper.cpp).

  1. EntradaInput — texto tecleado, audio del micro o una foto (cámara/galería). — typed text, mic audio or a photo (camera/gallery).
  2. VAD / OCR — Silero VAD recorta el habla; PaddleOCR PP-OCR extrae el texto de la imagen. Ambos con ONNX Runtime. — Silero VAD trims the speech; PaddleOCR PP-OCR extracts text from the image. Both via ONNX Runtime.
  3. Whisper (ASR) — si la entrada fue la voz, whisper.cpp la transcribe offline al idioma origen. — if the input was speech, whisper.cpp transcribes it offline in the source language.
  4. NLLB-200 (ONNX) — el encoder y el decoder merged de NLLB-200-distilled-600M (int8) traducen por ONNX Runtime, frase a frase; el tokenizador BPE va en Kotlin puro. — the NLLB-200-distilled-600M encoder and merged decoder (int8) translate via ONNX Runtime, sentence by sentence; the BPE tokenizer is pure Kotlin.
  5. Piper (TTS) — opcionalmente, la traducción se lee en voz alta con una voz neuronal local. — optionally, the translation is read aloud with a local neural voice.
  6. Historial — el par origen → traducción se guarda en una base de datos local. — the source → translation pair is saved to a local database.

Modelos y primer usoModels and first run

El motor de traducción es NLLB-200-distilled-600M (int8, ONNX). La primera vez la app descarga los modelos (~900 MB) y los guarda en su almacenamiento privado; después ya no necesita red.

The translation engine is NLLB-200-distilled-600M (int8, ONNX). On first run the app downloads the models (~900 MB) into its private storage; after that it no longer needs the network.

Modelos NLLB (para importar desde el móvil)NLLB models (to import from the phone)

Descarga estos 3 ficheros a una misma carpeta del móvil y luego: app → Ajustes → Modelo de traducción (NLLB-200 · ONNX) → Importar modelos NLLB → elige la carpeta. La app los copia a su memoria interna y ya no descarga nada.

En la variante FULL los modelos ya vienen incluidos (la importación es opcional); en la LITE hay que importarlos o dejar que se descarguen en el primer arranque.

Download these 3 files into one folder on the phone, then: app → Settings → Translation model (NLLB-200 · ONNX) → Import NLLB models → pick the folder. The app copies them to internal storage and downloads nothing.

On the FULL build the models are already included (import is optional); on LITE you either import them or let them download on first run.

CompilarBuild

Requisitos: JDK 17, Android SDK 35, NDK 27.0.12077973, CMake 3.22.1. La parte nativa (whisper.cpp) se compila con el NDK en arm64-v8a; NLLB-200 corre por ONNX Runtime (sin llama.cpp).

Requirements: JDK 17, Android SDK 35, NDK 27.0.12077973, CMake 3.22.1. The native part (whisper.cpp) is built with the NDK for arm64-v8a; NLLB-200 runs via ONNX Runtime (no llama.cpp).

# 1. Native library / Librería nativa (whisper.cpp)
./scripts/fetch-deps.sh
LIBS=whisper ./scripts/build_native.sh

# 2. The app / La app
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest

# 2b. FULL variant / variante FULL (all models bundled / todo incluido)
./scripts/fetch_bundled_assets.sh
./gradlew :app:assembleDebug -Pbundled=true

# 3. Install / Instalar
adb install -r app/build/outputs/apk/debug/app-debug.apk

APK de depuración: app/build/outputs/apk/debug/app-debug.apk (solo arm64-v8a).Debug APK: app/build/outputs/apk/debug/app-debug.apk (arm64-v8a only).
